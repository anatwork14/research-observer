---
name: compare-evidence
description: Compare claims, experiments, results, papers, or decisions in a Research Observer workspace. Use when the user asks whether sources agree, conflict, support a decision, or leave a research question unresolved.
---

1. Identify each source precisely: note ID/file, PDF/page, figure, dataset, or result.
2. State what each source actually establishes before comparing them.
3. Normalize comparison dimensions such as population/dataset, method, metric, date/version, assumptions, and uncertainty.
4. Treat missing evidence as missing; do not fill gaps with plausible values.
5. Label relationships conservatively: supports, contradicts, partially supports, incomparable, or unresolved.
6. If proposing a new synthesis/decision note, cite the contributing research objects explicitly.
7. Preserve contrary evidence rather than rewriting it away.
8. Run `npm run doctor` after any workspace edit.
